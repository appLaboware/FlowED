# FlowDisP 0.3 Seed launcher

After extracting the 0.3 Seed package inside a project's `_dev/` directory, the normative launcher is:

`_dev/FLOWDISP-SEED-PROMPT.md`

Tell the new AI session only:

> Leia `_dev/FLOWDISP-SEED-PROMPT.md` e siga-o integralmente.

The launcher requires chronological Seed Replay of `_dev/discovery/flowdisp/seed/ROLL/PRIMARY.*`, indexes `_dev/discovery/flowdisp/seed/FD_artifacts/`, materializes derived replay state under `_dev/discovery/flowdisp/replay/`, commits one checkpoint per processed chunk, performs reverse forensic audit, and only then frames bounded `FDP-RC-xxx` Research Cases and ABR prompts.
