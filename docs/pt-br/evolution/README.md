# Evolução conceitual do FlowED

**Status:** registro de trabalho — não normativo
**Objetivo:** preservar decisões, hipóteses, correções e candidatos de pesquisa surgidos durante a reformulação do FlowED antes da escrita do novo manifesto e antes da busca do artigo-pai.

Este diretório existe para impedir que ideias discutidas desapareçam antes de serem formalizadas. Nada aqui deve ser tratado automaticamente como princípio científico, norma ou decisão definitiva do FlowED. Cada item deve futuramente receber pesquisa de anterioridade, terminologia estabelecida, evidências e status explícito.

## Regra de trabalho

1. Primeiro descrevemos corretamente o "animal" FlowED.
2. Depois pesquisamos a literatura e normas para cada proposição.
3. Se existir uma teoria/artigo que cubra adequadamente o todo, ele pode ser adotado como pai conceitual.
4. Se não existir um único pai adequado, os antecedentes científicos tornam-se "avós" e um artigo de síntese deve ser produzido como pai conceitual direto.
5. FlowED será então uma materialização de referência dessa teoria, e não sua autoridade epistemológica.
6. O próprio baseline FlowED permanece contestável e evolutivo.

## Arquivos

- `CONCEPTUAL-MODEL.md` — o animal FlowED atualmente entendido.

- `MEASUREMENT-CERTIFICATION-AND-RISK.md` — scores, maturidade, certificação não binária, risco e comparação com baseline.
- `RESEARCH-AGENDA.md` — candidatos a papers e perguntas de pesquisa.
- `PRODUCT-AND-TOOL-IDEAS.md` — ferramentas e produtos derivados das ideias atuais.
- `SESSION-LEDGER-2026-09-08.md` — ledger consolidado desta rodada de descoberta.

## Princípio de cautela

Não usar nomes inventados como se fossem termos estabelecidos. Expressões como "Full FlowED", "Baseline Alignment", "Referência", "Risco-FlowED" e outras permanecem nomes de trabalho até pesquisa terminológica específica.
