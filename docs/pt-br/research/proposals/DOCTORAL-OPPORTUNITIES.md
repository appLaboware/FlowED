# FlowED — Oportunidades de Pesquisa / Doutorado

**Status:** WORKING INDEX / UNVALIDATED  
**Domínio:** FlowED  

Este índice registra oportunidades de pesquisa com potencial de aprofundamento em nível de doutorado. A presença neste arquivo **não constitui alegação de novidade**. Cada oportunidade deve passar por busca sistemática de prior art, falsificação adversarial e validação metodológica antes de ser promovida a tese.

## Critério de entrada

Uma oportunidade entra neste índice quando existe pelo menos uma pergunta científica potencialmente não trivial, mensurável e falsificável, e quando o FlowED pode servir como laboratório sem ser usado como justificativa circular da própria hipótese.

## Oportunidades registradas

### FLOWED-RESEARCH-UOL-001 — Linguagem Operacional Uniforme e Conhecimento Instrumental

**Arquivo:** `UNIFIED-OPERATIONAL-LANGUAGE-AND-INSTRUMENTAL-KNOWLEDGE-HYPOTHESIS-v0.1.md`

**Questão central:** em que medida uma linguagem operacional uniforme reduz conhecimento instrumental para operar toolchains heterogêneas sem reduzir compreensão conceitual dos domínios nem criar dependência operacional do orquestrador?

**Status:** RESEARCH PROPOSAL / UNVALIDATED.

### FLOWED-RESEARCH-OBS-001 — Observabilidade Empírica e Evidência de Execução

**Arquivo:** `EMPIRICAL-OBSERVABILITY-AND-EXECUTION-EVIDENCE-v0.1.md`

**Questão central:** como instrumentar execuções de engenharia de forma suficientemente estruturada para comparação empírica de custo, qualidade, intervenção humana, contexto e reprodutibilidade, mantendo separação entre telemetria operacional e pesquisa?

**Status:** RESEARCH PROPOSAL / UNVALIDATED.

### FLOWED-RESEARCH-MNF-001 — Princípio da Mínima Fatoração Necessária

**Arquivo:** `MINIMUM-NECESSARY-FACTORIZATION-PRINCIPLE-v0.1.md`

**Questão central:** é possível reduzir sistematicamente a quantidade de propriedade de software nova necessária para realizar uma intenção, por meio de um protocolo evidence-based de sourcing, reutilização e composição, mantendo ou melhorando qualidade, diferenciação, sustentabilidade e independência operacional?

**Residual científico candidato:** não é `reuse before build`, que já possui prior art forte. O residual a investigar está na formalização, medição e validação de uma superfície proprietária mínima após `ADOPT / CONFIGURE / EXTEND / COMPOSE / ADAPT / FORK`, incluindo MNF-B/MNF-W, evidência, confiança e comportamento longitudinal.

**Status:** RESEARCH PROPOSAL / UNVALIDATED; oportunidade de doutorado sujeita a systematic prior-art gate.

## Regra de promoção

Nenhuma oportunidade deste índice deve ser descrita como contribuição inédita antes de:

1. systematic mapping / systematic literature review apropriada;
2. busca de standards, patents e literatura adjacente quando pertinente;
3. comparação com métodos e ferramentas existentes;
4. identificação explícita do residual científico;
5. hipótese falsificável;
6. desenho experimental plausível;
7. critérios objetivos de NO-GO científico.

## Princípio

> **Não usar o FlowED para justificar uma tese. Encontrar primeiro uma pergunta científica que sobreviva ao prior art; usar o FlowED somente quando ele for um instrumento adequado para investigá-la.**
