# MyTrues Core

This directory is intentionally empty of proprietary decision logic.

Rule:

> public knowledge stays public; only demonstrably original added value belongs here.

A future Core may contain proprietary implementation only after experiments show
that it adds measurable value over the open baseline, for example:

- better candidate ranking;
- better evidence fusion;
- better calibration;
- better conflict resolution;
- better outcome-driven adaptation;
- better senior-specific decision quality.

Until then, MyTrues runs entirely on the open/reference surface.

No proprietary advantage is claimed by this prototype.
