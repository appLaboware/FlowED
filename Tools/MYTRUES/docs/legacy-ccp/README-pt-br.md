## 🎯 O que é o MyTrues?

MyTrues é um **protocolo universal para gestão de conhecimento experiencial** que transforma decisões de equipe, aprendizados e insights em "verdades" estruturadas, pesquisáveis e compartilháveis.

Em vez de perder conhecimento valioso em documentos espalhados, mensagens de chat ou sabedoria tribal, o MyTrues captura o **Caminho Cognitivo do Criador** (CCP) de cada decisão importante que sua equipe toma.

## ✨ Recursos Principais

### 🏗️ **Gestão Estruturada de Verdades**

- **Framework CCP**: Rastreamento do Caminho Cognitivo do Criador
- **Organização Hierárquica**: Categorias aninhadas e indexação semântica
- **Baseado em Templates**: Formatação consistente de verdades
- **Rastreamento de Evolução**: Veja como as decisões evoluem ao longo do tempo
- **Refinamento Cognitivo**: Transforme caminhos brutos caóticos em cognição linear otimizada
- **Anexos Multimídia**: Suporte para imagens, vídeos, documentos e conteúdo interativo
- **Sistema de Formato Duplo**: Conteúdo legível por humanos + descrições otimizadas para LLM

### 🤖 **Inteligência Potencializada por IA**

- **Busca Semântica**: Encontre verdades por conceito, não apenas palavras-chave
- **Base de Conhecimento Neural**: Exporte verdades como dados de treinamento para LLM
- **Sugestões Inteligentes**: Recomendações orientadas por IA baseadas em contexto
- **Prompts Dinâmicos**: Gere prompts de IA contextuais a partir de suas verdades

### ⚡ **Experiência Developer-First**

- **Ferramentas CLI**: Interface completa de linha de comando para automação
- **Integração Git**: Controle de versão para seu conhecimento
- **Pronto para API**: APIs RESTful para integrações
- **Nativo em Markdown**: Legível por humanos, amigável para ferramentas

### 🌐 **Compartilhamento de Conhecimento Federado**

- **Clusters de Equipe**: Bases de conhecimento privadas
- **Polinização Cruzada**: Compartilhamento anônimo de experiências
- **Marketplace**: Experiências verificadas premium
- **Padrão de Protocolo**: Especificação aberta para adoção universal

## 🚀 Início Rápido

### Instalação

```bash
# Clone o repositório
git clone https://github.com/MyTrues/MyTrues.git
cd MyTrues

# Torne o CLI executável
chmod +x MyTrues.sh

# Crie sua primeira verdade
./MyTrues.sh create
```

### Uso Básico

```bash
# Liste todas as verdades
./MyTrues.sh list

# Busque verdades
./MyTrues.sh search "autenticação"

# Mostre verdade específica
./MyTrues.sh show CORE/auth-strategy

# Crie nova verdade
./MyTrues.sh create SECURITY/oauth-implementation

# Arquive verdade desatualizada
./MyTrues.sh archive LEGACY/old-auth-method

# Comandos de refinamento cognitivo
./MyTrues.sh refine CORE/auth-strategy    # Converta CCP bruto para estado refinado
./MyTrues.sh raw CORE/auth-strategy       # Visualize caminho cognitivo bruto
./MyTrues.sh refined CORE/auth-strategy   # Visualize caminho cognitivo refinado

# Comandos de gestão de anexos
./MyTrues.sh attach CORE/auth-strategy logo.png "Evolução do logo v1 a v3"
./MyTrues.sh attachments CORE/auth-strategy    # Liste todos os anexos
./MyTrues.sh view-attachment CORE/auth-strategy logo.png
./MyTrues.sh llm-describe CORE/auth-strategy   # Obtenha descrição otimizada para LLM
```

## 🌟 A Visão: MTP (Protocolo MyTrues)

MyTrues não é apenas documentação—é a fundação para **inteligência de conhecimento universal**:

### 🌐 **Arquitetura Protocol-First**
- **Padrão MTP**: Especificação aberta para troca de conhecimento entre organizações
- **Nativo em API**: Cada instância MyTrues se torna um endpoint de conhecimento
- **Rede Federada**: Empresas podem expor e consumir sabedoria através de protocolos padronizados
- **Interoperável**: Compartilhamento de conhecimento multiplataforma e multi-indústria

### 🧠 **Aplicações de Inteligência Coletiva**
- **Conhecimento Neural**: Transforme sabedoria de equipe em dados de treinamento de IA
- **Geração Dinâmica**: Auto-crie documentos normativos, código e políticas a partir de análise CCP
- **Federação Global**: Compartilhe experiências anonimizadas entre organizações mundialmente
- **IA Contextual**: Gere código e decisões mais inteligentes baseados em experiência coletiva real
