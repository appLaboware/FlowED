## Method

This inventory enumerates every repository returned by the GitHub installations
currently available to this session, plus additional organization-member
repositories discovered through affiliation enumeration.

Search signals used:

- `MyTrues`;
- `Caminho Cognitivo`;
- `Experiential Decision Theory`;
- targeted tree inspection for obvious InitProj/MyTrues snapshots where code
  search indexing was incomplete.

Classification:

- **TRACE-PRIMARY / TRACE-ORIGIN / TRACE-SPEC / TRACE-HISTORICAL / TRACE-DUPLICATE / TRACE-CURRENT** — direct MyTrues lineage;
- **RELATED** — MyTrues mentioned/integrated but not a source lineage;
- **DESCENDANT?** — conceptual descendant worth review, but no direct MyTrues identity proved;
- **NONE** — no strong MyTrues/CCP/EDT trace found by this pass.

A `NONE` result means “no strong trace found with the available search/index
surface”, not a mathematical proof that the repository never contained the term.
