Status: **ARCHAEOLOGY / SOURCE-PROVENANCE INDEX — NOT NORMATIVE**

## Purpose

This is the final uploaded chat-extraction batch supplied for the current
MyTrues archaeology pass.

As with prior batches, every Markdown file is a **secondary extraction report**
generated inside another ChatGPT conversation.

The goal is to preserve only:

- genuinely new lineage;
- strong negative evidence;
- explicit PO statements quoted by the report;
- unresolved contradictions that require original-chat forensics.

No report is allowed to silently redefine the current executable MyTrues v0.2.

## Source-confidence classes

- **A — chat-local extraction:** explicitly restricted to that conversation.
- **B — mixed reconstruction:** incorporates compacted history, other branches,
  prior extracts or project context.
- **C — consolidation/index:** mainly restates previously recovered history.
