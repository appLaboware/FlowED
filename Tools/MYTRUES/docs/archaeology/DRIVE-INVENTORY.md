## Drive material versus GitHub material

Drive contributes three things the GitHub archaeology did not preserve as
clearly:

1. **earlier chronology** — CCW from February 2025 predates stabilized MyTrues;
2. **working corpus examples** — concrete TRUE/cognition pairs from real project
   decisions;
3. **Science Frontier methodology** — the September 2026 discovery contract.

GitHub remains stronger for executable source history and immutable blob/commit
provenance.

Drive remains stronger for pre-repository conceptual artifacts and exported
working material.
