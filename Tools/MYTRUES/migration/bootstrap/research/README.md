## Rule

A paper opportunity becomes an active claim only after:

1. prior art is current;
2. strongest practical baselines are runnable;
3. task/benchmark is frozen;
4. metrics are declared before results;
5. negative results are retained;
6. residual contribution survives direct comparison.

Microsoft Research, Google Research/DeepMind and top conference work are used as
baselines/references, not as branding.
