## Private-first rule

Every definitive repository begins PRIVATE.

A repository may become public only after an explicit release review confirms:

1. no secrets/private customer/provider data;
2. no unpublished thesis material that should remain private;
3. license compatibility;
4. copyright/provenance of imported material;
5. repository boundary is correct;
6. README/SECURITY/GOVERNANCE are present;
7. intended public license(s) are explicit;
8. tests/conformance appropriate to the repository pass;
9. public description/topics are reviewed;
10. publication is an explicit PO action.

"planned-public" is metadata only. It is not a license grant.
