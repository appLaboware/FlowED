# MyTrues

Status: PRIVATE PRE-RELEASE

MyTrues is the open/common technical product layer for explicit decision memory,
authority, provenance, temporal decision history, replaceable DecisionEngines,
ports/adapters and conformance.

## Open boundary target

The future public/common layer includes:

- wire protocol;
- schemas;
- lifecycle semantics;
- port contracts;
- DecisionEngine interoperability boundary;
- plugin manifest contract;
- conformance suite;
- reference implementation;
- reference persistence;
- open adapters;
- authority / candidate-to-canonical rules.

Independent engines and plugins may be open or closed as long as they implement
the open contracts.

## Not this repository

- EDT thesis manuscript;
- broad research archaeology;
- proprietary enterprise engines;
- customer/provider private memory.

## Current baseline

The current executable baseline is the provider-scoped v0.2 decision protocol:
known/unknown, pause, sanitize, resolve, retain, resume and restart persistence.

Research hypotheses do not silently modify that baseline.
