# EDT — Education-Driven Thinking

Status: PRIVATE DOCTORAL RESEARCH

EDT is a conceptual/philosophical engineering thesis.

Its central object is the Creator Cognitive Path (CCP).

MyTrues is a technical instrument/reference implementation that can operationalize
and indirectly test aspects of CCP. MyTrues does not define EDT.

## Current research hierarchy

EDT
-> conceptual thesis

CCP
-> central concept/object of investigation

MyTrues
-> technical instrument and independent product/research opportunity

## Historical naming

Education-Driven Things existed as a temporary human-created naming branch in a
later workstream.

The current canonical thesis identity is Education-Driven Thinking.
