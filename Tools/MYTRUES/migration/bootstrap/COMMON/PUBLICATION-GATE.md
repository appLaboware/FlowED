# Publication Gate

A repository remains PRIVATE until all gates below are satisfied.

## G0 — Repository boundary
The repository contains only material belonging to its declared bounded context.

## G1 — Secrets and private data
No credentials, tokens, private customer/provider data, private prompts, internal
operational secrets, or restricted datasets are present.

## G2 — Provenance
Every imported third-party source has a known origin and compatible use terms.

## G3 — License
Public licenses are explicit by material type. No blanket relicensing of
third-party content.

## G4 — Research embargo
Unpublished thesis/paper material is intentionally selected for release.

## G5 — Security
SECURITY.md exists where software is distributed; security-sensitive defaults
have been reviewed.

## G6 — Conformance/tests
Required tests, schemas, examples and conformance evidence pass.

## G7 — Documentation
README clearly states scope, non-scope, maturity and dependency boundaries.

## G8 — Public metadata
Description, topics and homepage are reviewed for public use.

## G9 — PO authorization
Publication is an explicit human PO action.

Passing G0-G8 does not imply G9.
