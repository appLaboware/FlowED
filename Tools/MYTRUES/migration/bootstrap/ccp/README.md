# CCP — Creator Cognitive Path

Status: PRIVATE PRE-RELEASE / PLANNED PUBLIC

CCP (Caminho Cognitivo do Criador / Creator Cognitive Path) is the conceptual
object investigated by Education-Driven Thinking.

A useful current decomposition is:

SOURCE -> CCP -> PROJECTION

SOURCE is what was actually said, done or observed.

CCP is a structured representation of selected creator-cognitive keyframes such
as questions, alternatives, rationale, evidence, rejected paths, decisions and
revisions.

PROJECTION is a derived view such as NORM, ADR, explanation, learning material or
timeline.

## Important boundaries

- raw log != CCP;
- source != extraction != inference != confirmation != evidence != projection;
- provenance != rationale;
- chronology != causality;
- a readable projection does not become authority merely by being readable;
- CCP does not require exhaustive capture of hidden internal reasoning.

This repository must remain conceptually independent of one MyTrues runtime.
