# MyTrues Registry

Status: PRIVATE PRE-RELEASE / PLANNED PUBLIC

Open-registry target for MyTrues-compatible:

- DecisionEngines;
- memory adapters;
- DecisionProfile adapters;
- provenance/evidence adapters;
- CognitionProposal plugins;
- retrieval plugins;
- Source/View/Outcome integrations;
- MCP adapters.

Publication in the registry does not imply:

- conformance;
- security review;
- benchmarking;
- scientific reproduction;
- endorsement.

Those states must be represented separately.
