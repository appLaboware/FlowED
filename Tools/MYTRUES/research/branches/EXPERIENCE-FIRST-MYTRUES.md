## Why this branch matters

The executable MyTrues staging is currently an **Open Decision Protocol**.

This branch records a later conceptual expansion in which the primary object
becomes:

`Experience`

and a decision becomes one possible state/derivative in a broader epistemic
history.

The branch therefore poses a genuine bounded-context question.

## Claimed pivot

Earlier narrow identity:

```text
MyTrues
≈ decision memory
```

Experience-first branch:

```text
Experience
-> Belief / Argument
-> under Values + Context
-> Position
-> Decision
```

Associated phrase:

`MyTrues is the SQL of experience.`

This must not replace the current product definition until primary evidence
establishes whether the PO explicitly promoted the pivot.

## Core research invariants recorded by the branch

The reconstruction labels the following as promoted directions:

1. Experience is the primary conceptual unit, not Opinion.
2. Time is semantic, not merely one timestamp.
3. `NO RETROACTIVE COGNITION`.
4. `KNOWN != CONSIDERED != INFLUENCED`.
5. `NO INFERRED CAUSALITY AS FACT`.
6. `NO COGNITION WITHOUT PROVENANCE`.
7. Raw Source and Derived Cognition are distinct.
8. Defeated paths should be preserved.
9. Context participates in applicability.
10. `BEST_OBSERVED != SUCCESS`.
11. `UNKNOWN` remains unknown.
12. LLM is not epistemic authority.
13. Provider/model should be replaceable.
14. Memory should belong to the user/authorized organization.
15. Vector/embedding is derived index, not truth.
16. Persistent state must survive disposable runtime.
17. MyTrues is not EDT, Experimentation or InterMembers.
18. Adopt before building.

Only invariants already independently promoted elsewhere should be considered
current design rules. The others remain research candidates until the branch is
forensically qualified.
