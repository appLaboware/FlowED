# Project Genesis — Staged Discovery Protocol v0.1

Status: `EXPERIMENTAL / DOGFOOD-DERIVED / UNVALIDATED`

## Purpose

Separate the Project Genesis journey into explicit phases so that understanding, scientific boundary mapping, consolidation, realization analysis, novelty assessment, commercial viability, identity and project birth do not contaminate each other.

## Core sequence

```text
PHASE 01 — ORIGINATOR UNDERSTANDING
    ↓
PHASE 02 — INDEPENDENT SCIENCE-BOUNDARY INVESTIGATION
    ↓
PHASE 03 — SCIENCE-BOUNDARY CONSOLIDATION
    ↓
PHASE 04 — HUMAN-TARGET GAP / REALIZATION INVESTIGATION
    ↓
PHASE 05 — ADOPTION / COMPOSITION / RESIDUAL CONTRIBUTION
    ↓
PHASE 06 — THEORETICAL / PRACTICAL NOVELTY VIABILITY
    ↓
PHASE 07 — COMMERCIAL VIABILITY
    ↓
PHASE 08 — NAME / DOMAIN / IDENTITY
    ↓
PHASE 09 — PROJECT BIRTH RECORD / DURABLE SEED
```

## Global laws

1. No downstream phase may silently rewrite an upstream homologated artifact.
2. Every phase has an explicit entry gate and exit artifact.
3. A phase may return to an upstream phase when new evidence shows the upstream representation was insufficient.
4. `NOT_FOUND_IN_SCOPE` never means `DOES_NOT_EXIST`.
5. Evidence, inference, preference and decision must remain distinguishable.
6. No global GO/NO-GO is produced by the protocol unless a later explicitly authorized human decision stage requests it.
7. Every external investigation must preserve provenance and independent-run identity.
8. Every consolidated conclusion must trace back to named source reports and, when factual, to admissible evidence.

## Phase 01 — Originator Understanding

Goal: understand the idea before judging possibility, viability, novelty or merit.

Entry: raw exposition by originator.

Exit: `PREANALYSIS-UNDERSTANDING-RECORD`, homologated by the originator.

Mandatory rule:

> **NO EVALUATION BEFORE UNDERSTANDING SUFFICIENCY.**

The conductor may answer direct questions from the originator, but must not use the answer to steer continuation or abandonment. If the originator asks for an opinion before sufficient understanding exists, the conductor must state what is still missing before such an opinion could be responsibly formed.

## Phase 02 — Independent Science-Boundary Investigation

Goal: map what science and practice already establish, independently across multiple consultants.

Entry: homologated Phase 01 record.

Exit: one normalized `SCIENCE-BOUNDARY-CONSULTANT-REPORT` per consultant.

No consultant sees another consultant report.

## Phase 03 — Science-Boundary Consolidation

Goal: consolidate independent reports into one evidence-traceable boundary map.

Entry: set of normalized consultant reports.

Exit: one `SCIENCE-BOUNDARY-CONSOLIDATED-RECORD` using the same conceptual schema as the consultant reports plus explicit cross-report provenance.

Consensus is not majority vote. Divergence is evidence.

## Later phases

Phases 04–09 are intentionally not fully specified in this version. They are downstream placeholders and must be protocolized through dogfood before being treated as stable.

## Promotion rule

A rule discovered in a special-case overlay or self-dogfood remains local until it survives external cases and is explicitly promoted to this generic protocol.
