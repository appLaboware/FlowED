# 01 — Problema, fronteira e lineage

## Gatilho

O trabalho de prior art revelou uma falha de processo: uma ideia pode parecer coerente, útil e característica do FlowED antes de sabermos quanto dela já existe. Em alguns momentos a redação editorial aproximou-se de promessas de contribuição antes de a fronteira dos antecedentes estar estabelecida.

Correção central:

```text
VALOR != CONTRIBUIÇÃO != INEDITISMO
```

Valor não exige novidade. Contribuição pode estar em composição, reponderação, operacionalização, arquitetura ou evidência. Ineditismo é um claim epistemológico separado.

## Estado padrão

Para distintividade/originalidade, o default candidato é:

```text
UNRESOLVED
```

Novidade não é premissa; é eventual conclusão limitada por escopo, corpus, evidência e confiança.

## Fronteira primeiro, disposição depois

Cada princípio, capacidade ou claim importante deve ser pesquisado isoladamente:

```text
OBJETO
→ domínio existente
→ antecedentes mais próximos
→ o que realmente cobrem
→ onde a fronteira termina
→ residual
→ disposição
```

Família de disposições candidata:

- `ADOPT` — usar substancialmente como existe;
- `CONFIGURE / PERSONALIZE` — parametrizar ou especializar;
- `EXTEND / OVERLAY` — manter a base e acrescentar camada;
- `COMPOSE` — combinar elementos existentes;
- `FORK / MODIFY` — derivar diretamente e alterar internamente;
- `DERIVE / INSPIRE` — reconhecer ancestralidade material, mas reconstruir de modo independente e divergente;
- `BUILD RESIDUAL` — construir somente o que permaneceu sem correspondência suficiente;
- `UNRESOLVED` — evidência ainda insuficiente.

A disposição deve seguir a evidência, nunca a preferência por código próprio ou uma narrativa mais forte de originalidade.

## Regra ética de ancestralidade

Mesmo que um residual final seja defensavelmente novo, a novidade não apaga a base que tornou a ideia possível.

```text
existia
→ adotamos
→ configuramos
→ estendemos
→ compusemos
→ derivamos/transformamos
→ residual
→ claim permitido sobre o residual
```

Isso vale para ciência, manifesto, método, arquitetura, produto e código.

## Releitura de “De onde partimos”

“De onde partimos” não deveria separar retoricamente “o velho” de “o nosso”. A hipótese mais forte é tratá-lo como uma projeção de lineage/provenance:

```text
antecedente
→ evidência
→ limite
→ herança
→ composição/reponderação/transformação
→ residual
→ estado epistemológico
```

Ainda não se decide se isso exige um novo tipo chamado “CCP de Partida”. Primeiro deve ser demonstrado que o modelo atual de CCP não é suficiente.
